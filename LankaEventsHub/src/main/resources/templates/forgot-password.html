Account security

Reset links are short-lived on purpose.

A link expires 30 minutes after it is created.
Each link works exactly once.
Resetting your password retires every other outstanding link for your account, so an older one cannot be used afterwards.
Only a hash of the link is ever stored — a copy of the database contains no usable reset links.
